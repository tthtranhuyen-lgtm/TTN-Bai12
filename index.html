🎒 Không thể tải ứng dụng trên GitHub Pages

Nếu bạn đang mở từ GitHub Pages và gặp màn hình này, nguyên nhân phổ biến nhất là GitHub Pages đang phục vụ trực tiếp nhánh gốc (main) thay vì bản build từ GitHub Actions.

Cách khắc phục trên GitHub:
1. Vào Settings → Pages trong repository GitHub.
2. Ở mục Build and deployment → Source, đổi thành GitHub Actions.
3. Vào tab Actions và chạy lại workflow Deploy to GitHub Pages.
